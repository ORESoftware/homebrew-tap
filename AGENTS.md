# Tap maintenance

Follow https://github.com/ORESoftware/my-ai/blob/main/AGENTS.md and its linked
original-agents.md. This is a public tap: never place private package formulae,
private source/artifacts, credentials, or token-bearing URLs here.

Use immutable release URLs and verified SHA-256 digests. Preserve existing
formulae. New publication work goes through a pull request with native Homebrew
installation tests; use a history-preserving merge after checking the exact head.
